# Get FoldLink

Clean links, ready to share.

FoldLink is a Chrome extension that removes tracking parameters and turns URLs
into clean links, Markdown, short links, QR codes, or custom-formatted output.
This repository is the official public home for FoldLink downloads and release
notes.

## Status

FoldLink is in active development. The first public release will be published
on the [Releases](../../releases) page.

## Features

- Remove tracking parameters while preserving useful URL parameters.
- Copy clean URLs, Markdown links, short links, or custom templates.
- Generate QR codes for cleaned links.
- Process and copy multiple browser tabs in one workflow.
- Keep preferences in Chrome Sync and recent copy history on the local device.

## Install

FoldLink will be available from the Chrome Web Store. Until then, release
packages will be published on the [Releases](../../releases) page.

To install a release package manually:

1. Download and unzip the Chrome package from a release.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked**, then choose the unzipped extension folder.

## Privacy

FoldLink does not require an account. Extension preferences are stored through
Chrome Sync, while recent copy history and cached short-link results remain on
the local device. A short-link provider receives a URL only when you explicitly
create a short link.
